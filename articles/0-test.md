# دليل شامل لخصائص لغة Markdown

ملف مرجعي (Cheat Sheet) يجمع أهم خصائص لغة الماركداون، كل عنصر موضح بشكله بعد ما يترندر (Rendered)، وتحته الكود اللي بيكتبه.

---

## 1. عرض Markdown (إزاي بيشتغل)

Markdown هي لغة تنسيق بسيطة، بتكتب بيها نص عادي فيه رموز معينة (زي `#` و `*` و `>`)، وبعدين أي برنامج بيدعم Markdown (زي GitHub، Notion، VS Code، وحتى واتساب) بيحوّل الرموز دي لتنسيق فعلي.

يعني السطر ده لما يتكتب:

```
**كلمة مهمة**
```

بيتحول بعد الرندرة (Rendering) لـ:

**كلمة مهمة**

الملف الأصلي (Raw) بيفضل نص عادي تقدر تفتحه بأي محرر نصوص، لكن الشكل المنسق ده بيظهر بس في البرامج اللي بتفهم Markdown.

---

## 2. العناوين (Headings)

فيه 6 مستويات من العناوين، كل مستوى بعلامة `#` أكتر من اللي قبله:

# عنوان مستوى 1

## عنوان مستوى 2

### عنوان مستوى 3

#### عنوان مستوى 4

##### عنوان مستوى 5

###### عنوان مستوى 6

**الكود:**

```
# عنوان مستوى 1
## عنوان مستوى 2
### عنوان مستوى 3
#### عنوان مستوى 4
##### عنوان مستوى 5
###### عنوان مستوى 6
```

> لازم تسيب مسافة بعد علامة `#` عشان العنوان يشتغل صح.

## 3. تنسيق النصوص (Bold / Italic)

|الشكل النهائي|الكود|
|---|---|
|**نص عريض**|`**نص عريض**`|
|_نص مائل_|`*نص مائل*`|
|_**عريض ومائل مع بعض**_|`***نص***`|
|~~نص مشطوب~~|`~~نص~~`|

## 4. الاقتباسات (Blockquotes)

> ده اقتباس بسيط، بيتكتب بعلامة `>` في أول السطر.

> اقتباس
> 
> > اقتباس جوه اقتباس (متداخل)
> > 
> > > وممكن تتداخل مستويات أكتر

**الكود:**

```
> اقتباس بسيط
>> اقتباس متداخل
>>> ومتداخل أكتر
```

## 5. القوائم (Lists)

### أ. قائمة غير مرقمة

- عنصر أول
- عنصر تاني
    - عنصر فرعي جوه التاني
    - عنصر فرعي تاني
- عنصر تالت

**الكود:**

```
- عنصر أول
- عنصر تاني
  - عنصر فرعي جوه التاني
- عنصر تالت
```

### ب. قائمة مرقمة

1. الخطوة الأولى
2. الخطوة التانية
3. الخطوة التالتة

**الكود:**

```
1. الخطوة الأولى
2. الخطوة التانية
3. الخطوة التالتة
```

### ج. قائمة مهام (Checklist)

- [x] مهمة خلصت
- [ ] مهمة لسه هتتعمل

**الكود:**

```
- [x] مهمة خلصت
- [ ] مهمة لسه هتتعمل
```

## 6. الأكواد (Code)

### كود مضمّن جوه السطر (Inline Code)

لو عايز تكتب كلمة كـ كود جوه فقرة عادية، حوطها بعلامة `` ` `` من الطرفين، زي كده: `print("أهلاً")`

### كتلة كود كاملة (Code Block)

```python
def greet(name):
    print(f"أهلاً يا {name}")

greet("أحمد")
```

**طريقة الكتابة** (حوط الكود بـ 3 علامات ` قبله وبعده، واكتب اسم اللغة بعد أول علامة عشان يبان فيه تلوين تلقائي):

````
```python

    print(f"أهلاً يا {name}")
```
````

## 10. شكل الصفحة على الموبايل والكمبيوتر

ملف Markdown هو ملف نصي عادي 100%، معندوش Layout أو تصميم ثابت جواه. الشكل النهائي بيتحدد حسب البرنامج اللي بيفتح بيه الملف (GitHub، VS Code، Notion، Typora، وحتى واتساب)، ومعظم البرامج دي بتكون Responsive تلقائيًا وبتتأقلم مع حجم الشاشة من غير أي تدخل إضافي منك.

عشان تضمن إن الملف يبان كويس على أي شاشة (موبايل أو كمبيوتر)، فيه شوية قواعد بسيطة:

- **الأسطر:** خليها مش طويلة أوي، الأفضل حوالي 80 حرف في السطر، عشان القراءة تبقى مريحة على الشاشات الصغيرة.
- **الجداول:** لو فيها أعمدة كتير، ممكن تظهر مضغوطة أو تحتاج Scroll جانبي على الموبايل، فحاول تقلل عدد الأعمدة لو ينفع.
- **العناوين:** رتبها بشكل هرمي منطقي (H1 بعده H2 بعده H3...) عشان أي قارئ يقدر يتنقل بسهولة.
- **الصور:** متعتمدش على مقاس ثابت بالبكسل، سيب البرنامج اللي بيعرض الملف يتحكم في المقاس حسب الشاشة تلقائيًا.
