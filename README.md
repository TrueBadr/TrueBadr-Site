# TrueBadr Site

موقع مقالات شخصي بسيط مبني بـ React وVite، والمقالات محفوظة كملفات Markdown.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## إضافة مقال

أضف ملفًا جديدًا داخل `articles`، مثل `1-title.md`:

```md
---
id: 1
title: عنوان المقال
date: 2026-08-05
---

نص المقال هنا.
```

يجب أن يكون لكل مقال رقم `id` مختلف. الرابط الناتج سيكون `/1`.

## النشر

1. من GitHub افتح: `Settings → Pages`.
2. اختر `GitHub Actions` كمصدر النشر.
3. ارفع الملفات إلى فرع `main`.

كل Push جديد سيبني الموقع وينشره تلقائيًا.
